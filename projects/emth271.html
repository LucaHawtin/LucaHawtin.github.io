EMTH271 Heat Conduction Modelling

Two finite difference case studies modelling steady-state and transient heat conduction through a 2D body.

Timeline 2025
Team size 2 Students
Project Type Coursework
Course EMTH271, University of Canterbury
  • Python
  • Finite Difference Method
  • Numerical Modelling
  • Heat Transfer

For a mathematics course in 2025, I was tasked with modelling heat transfer through a rectangular body using the finite difference method (FDM). We worked through two case studies: a steady-state problem and a transient one.

The first case study modelled steady-state heat conduction through the body with mixed boundary conditions: a prescribed heat flux, a fixed temperature, an insulated edge, and convective heat transfer. The resulting system of equations was solved with Gauss-Seidel iteration.

To check that the solution could be trusted, we refined the mesh and watched how the results changed. The minimum and maximum temperatures converged as the mesh got finer, while the iteration count and solve time grew.

As a sanity check, we removed the convective boundary. The edge then behaved like an insulated wall, as expected, which confirmed the boundary conditions were working correctly.

We then extended the model to the transient case for a stainless-steel plate. Using the explicit finite difference method, the temperature field is stepped forward in time from an initial condition, with the time step limited by the stability criterion.

I built the solvers in Python using object-oriented programming: a Body class represents the 2D domain and its boundary conditions, and a Solver class implements the numerical methods. This made it easy to change the mesh resolution, boundary conditions and material properties, and to explore how each one affects the solution.
